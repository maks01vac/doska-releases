# Доска

Локальная доска для уроков и вебинаров по математике: перо для графического планшета, PDF и картинки, графики функций, чертежи по планиметрии и стереометрии. Работает без интернета, доски хранятся у вас на компьютере.

## Скачать

**[→ Последняя версия](https://github.com/maks01vac/doska-releases/releases/latest)** — внизу страницы, в разделе «Assets», выберите файл для своего компьютера (X.Y.Z — номер версии).

Нужно: macOS 13 Ventura или новее, либо Windows 10/11 (64-бит).

## Как установить

| Компьютер | Файл |
|---|---|
| Mac с процессором Apple (M1, M2, M3, M4) — почти все Mac после 2020 года | **Doska-X.Y.Z-mac-arm64.dmg** |
| Mac с процессором Intel | **Doska-X.Y.Z-mac-x64.dmg** |
| Windows 10 / 11 | **Doska-Setup-X.Y.Z.exe** |

Какой у вас Mac: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

### Mac
1. Откройте скачанный `.dmg` и перетащите «Доску» в папку «Программы».
2. Запустите «Доску» из «Программ». macOS скажет, что не может проверить разработчика, — нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», пролистайте вниз и нажмите «Всё равно открыть» рядом с «Доской». Введите пароль от Mac.

Это нужно сделать один раз. Если macOS пишет, что программа «повреждена», откройте «Терминал» и выполните:
`xattr -cr /Applications/Доска.app` — после этого «Доска» откроется.

### Windows
1. Запустите `Doska-Setup-X.Y.Z.exe`.
2. Если появится синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Установка займёт несколько секунд, ярлык «Доска» появится на рабочем столе.

### Обновления
«Доска» сама проверяет новые версии, скачивает их в фоне и предлагает перезапуститься. Доски при обновлении не трогаются: они лежат в папке «Документы/Доски».
